# Data sources and attribution

Original source inputs are retrieved from their providers rather than redistributed in this code upload. Exact file paths, URLs, sizes and checksums are in `data_sources.json`; source attribution is retained here. Derived tables are generated locally by the analysis programs. No patient-level or specimen-level data tables are committed to this repository.
