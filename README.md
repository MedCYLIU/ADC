# ADC target assessment in breast cancer

Code for *Specimen-dependent assessment of antibody–drug conjugate targets in breast cancer: A multicohort public-data study*.

This repository contains the analysis and plotting programs, package requirements, and source-data download instructions. Data tables, raw measurements, figures and manuscript files are not included.

## Setup

Tested with Python 3.12 on Windows. Plotting uses Arial installed at the standard Windows font location. Package versions are pinned in `requirements.txt`.

```sh
python -m pip install -r requirements.txt
```

## Run the analyses and figures

```sh
python download_data.py
python run_analysis.py
python render_figures.py
```

The downloader retrieves 24 original input files from the official sources listed in `data_sources.json` (about 133 MB) and verifies their sizes and SHA-256 checksums. The downloaded inputs remain local and are excluded by `.gitignore`.

For an exact offline rerun, import the inputs from the reproducibility archive accompanying the manuscript:

```sh
python download_data.py --from-archive "path/to/ADC_public_data_complete_package.zip"
python run_analysis.py
python render_figures.py
```

A checksum mismatch stops the workflow. Database responses can change; use the pinned archive when the live response differs from the recorded snapshot. The local TCGA manifest, `work/adc_v2/tcga/sources.json`, contains download metadata and checksums, not expression measurements.

`analysis_steps.json` lists the 13 analysis steps. The numerical code retains the original calculations and has been formatted for readability. The plotting scripts read the resulting analysis tables; statistical models are not refitted during plotting.

## Outputs

| Output | Local location |
|---|---|
| Derived analysis tables | Alongside the corresponding cohort scripts under `work/` |
| Six main figures | `work/adc_manu_revision/figures/` |
| Supplementary Figure 1 | `work/adc_v6/figures/` |
| Supplementary Figure 2 | `work/adc_v6/functional/` |

Main figures are written as vector PDFs and 600-dpi PNGs. The TCGA analysis also writes a diagnostic plot; the submitted figures are those generated by `render_figures.py`.

Checks against the archived outputs reproduced 18 numerical tables within 1e-12 and all eight figure images exactly in the tested Windows environment.

## Scope and attribution

The analyses use deposited measurements from TCGA-BRCA, AURORA US, UPTIDER, I-SPY2 and NCT02326974, plus published resistant-cell-model measurements. Cohort scales and denominators are kept separate. The analyses are exploratory and do not establish a clinical treatment-selection rule.

Original sources and their terms are listed in `DATA_SOURCES.md`. Downloaded data retain their source-specific terms. A software licence has not yet been selected by the authors. The manuscript reports the assistance used in programming, checks, drafting and figure preparation.
